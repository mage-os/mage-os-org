**Mage-OS Distribution 3.0** is built on **Magento Open Source 2.4.9**. Headline changes: a brand-new interactive installer, Return Merchandise Authorization (RMA) and Admin Activity Log, an "update available" indicator in the admin footer, better developer features, and an opt-in Minimal Distribution.

<Callout type="info" title="What's new in 3.0">

- **Interactive installer**: `bin/magento install` — guided wizard with service auto-detection and resume-on-failure
- Built on Magento Open Source 2.4.9
- PHP 8.5 added (PHP 8.2 dropped)
- Admin activity logging
- RMA requests and admin approval
- Optimized Varnish VCL configuration
- Customizable admin logo and icon
- Ignition error pages in developer mode
- Admin version update indicator
- New **Minimal Distribution** for lean, hand-composed installs
- Lazy-ghost object loading for better performance in PHP 8.4+

</Callout>

<Callout type="warning" title="Breaking changes — please read before upgrading">

- **PHP 8.2 is no longer supported.** Minimum is now PHP 8.3 (8.4 recommended).
- **Symfony 6.4 → 7.4 LTS.** Extensions type-hinting Symfony 6.x classes need updates.
- **Adobe analytics modules removed.** Any extensions referencing them will fail.

See the [Compatibility & upgrade notes](#compatibility--upgrade-notes) for the full list.

</Callout>

## What's new in Mage-OS 3.0

### Interactive installer: `bin/magento install`

All new, for easy setup of new Mage-OS installations:

```bash
bin/magento install
```

A guided wizard walks you through database, admin account, store config, services, sample data, and theme selection. Along the way it:

- **Auto-detects services** — MySQL/MariaDB, Redis, OpenSearch/Elasticsearch, and RabbitMQ on common ports.
- **Resumes on failure** — config is saved; the next run picks up where you left off (passwords are re-prompted).
- **Protects production** — explicit confirmations before destructive operations; warns if it suspects production.
- **Installs Hyvä Theme out of the box** — pick Hyvä during the theme step and the installer adds the Composer packages and applies the theme for you, no extra setup required.
- **Handles post-install setup** — applies the chosen theme, sets indexers to schedule mode, manages two-factor authentication (2FA), and flushes caches.

The original `setup:install` is unchanged, so automation isn't affected. Contributed by [@DavidLambauer](https://github.com/DavidLambauer), with 410 unit tests ([#191](https://github.com/mage-os/mageos-magento2/pull/191)).

![The interactive bin/magento install wizard detecting local services](~/assets/images/blog/2026/mageos-3-0-installer.png)

### PHP 8.5 ready, faster cold starts on 8.4

Mage-OS 3.0 supports PHP 8.5 alongside 8.3 and 8.4. We built in **PHP 8.4 lazy object loading** for faster response times.

### RMA

Mage-OS now includes built-in RMA support via `mage-os/module-rma`. Enable it in configuration after upgrading. Customers request returns from their account; merchants can review and approve requests, and communicate with the customer.

![Mage-OS RMA request management](~/assets/images/blog/2026/mageos-3-0-rma.png)

### Admin Activity Log

`mage-os/module-admin-activity-log` brings admin action logging — a built-in audit trail of who changed what, when, for auditing and compliance.

![The Admin Activity Log grid showing logged admin actions](~/assets/images/blog/2026/mageos-3-0-admin-activity-log.png)

### "Update available" indicator in the admin footer

The admin footer now shows an **"Update available: X.Y.Z"** link when a new release is available. The version check happens in the background, by directly checking your composer repositories. This can be disabled in configuration.

![The Mage-OS admin footer showing an 'Update available' notice](~/assets/images/blog/2026/mageos-3-0-update-indicator.png)

### Minimal Distribution

3.0 introduces `mage-os/product-minimal-edition` — a lean install with only ~98 core packages installed. Modules, themes, and language packs are available as individual Composer packages, so you only install what you use. Best for teams comfortable composing their own stack and looking to optimize every millsecond.

Browse the included packages and the full add-on set in our website's new [Package Browser](/product/minimal).

## Developer toolkit, bundled by default

Mage-OS 3.0 bundles four long-standing community tools out of the box, to make your experience better.

### n98-magerun2

The de-facto Magento command-line interface (CLI), now shipped by default. `sys:info`, `cache:flush`, `db:console`, `dev:console`, and dozens of inspection commands.

Run commands via `vendor/bin/n98-magerun2`.

Maintained by **[netz98 GmbH](https://github.com/netz98)** — Christian Münch ([@cmuench](https://github.com/cmuench)), Tom Klingenberg ([@kissifrot](https://github.com/kissifrot)) and the n98-magerun2 contributors.

### Ignition for Magento

Swissup Labs integration for `spatie/ignition`, a contextual error page. Developer mode exceptions will now give you a stack trace, request context, environment details, and editor-jump links. Auto disabled in production, so it can't leak internals.

![The Ignition styled error page shown in developer mode](~/assets/images/blog/2026/mageos-3-0-ignition.webp)

Maintained by **[Swissup Labs](https://github.com/swissup)**.

### Varnish Extended

Optimizations, richer cache controls, and operational tooling for using Varnish in production. Regenerate and update your Varnish VCL to apply the improvements after upgrading.

Maintained by **[Elgentos](https://github.com/elgentos)** — Peter Jaap Blaakmeer and the Elgentos team.

### Custom Admin Logo

Replace the admin panel and login-screen logo without touching a theme — a small but meaningful branding touch.

![Mage-OS admin with a custom logo applied](~/assets/images/blog/2026/mageos-3-0-custom-admin-logo.png)

Maintained by **[element119](https://github.com/element119)** — Kiel Pykett ([@kpykett](https://github.com/kpykett)).

## Compatibility & upgrade notes

- **PHP 8.3 minimum.** Composer will refuse to install Mage-OS 3.0 on PHP 8.2 or earlier. PHP 8.4 is recommended; 8.5 is supported.
- **Symfony 6 → 7.** Extensions type-hinting `symfony/console`, `symfony/intl`, `symfony/mailer`, `symfony/mime`, `symfony/process`, or `symfony/string` 6.x signatures need updates.
- **Adobe analytics removal.** Remove references to `module-analytics`, `module-catalog-analytics`, `module-customer-analytics`, `module-marketplace`, `module-quote-analytics`, `module-review-analytics`, `module-sales-analytics`, and `module-wishlist-analytics` before upgrading.
- **`ext-ftp` dropped.** No longer required out of box; hosting providers and container images can stop installing it.
- **`Magento_Backup` module removed.** The legacy `bin/magento setup:backup` command is gone — use filesystem and database backup tooling appropriate for your environment.
- If you encounter problems with lazy object loading, you can disable it in `app/etc/env.php` by setting `lazy_object_loading_disabled` to `true`.

## Installation

### New installations

```bash
composer create-project --repository-url=https://repo.mage-os.org/ mage-os/project-community-edition=3.0.0 <install-directory-name>
cd <install-directory-name>
bin/magento install
```

The wizard detects local services, walks you through configuration, and handles post-install setup. `bin/magento setup:install` still works if you prefer the classic flow.

For the lean install, see the [Minimal Distribution](/product/minimal) page.

### Upgrading Mage-OS

```bash
composer require mage-os/product-community-edition=^3.0 --no-update
composer update
bin/magento setup:upgrade
```
